# Subir a GitHub (repositorio NUEVO; no toca el de la Primera Entrega)
1. En GitHub: New repository → `etl-project-delivery-2-team-X` (vacío, sin README/.gitignore).
2. Dentro de esta carpeta (ya es un repo git con 1 commit en `main`):
```bash
git remote add origin https://github.com/<usuario>/etl-project-delivery-2-team-X.git
git push -u origin main
```
3. En README.md reemplazar ⟦URL del repo de la Primera Entrega⟧ y los ⟦responsables⟧. No hace falta clonar ni modificar el repo anterior.
